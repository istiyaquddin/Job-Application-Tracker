# 💼 Job Application Tracker

A modern and responsive **Job Application Tracker** that helps job seekers organize and monitor their job applications in one place.

Designed with a clean UI and intuitive workflow, this project makes it easy to track application status, manage opportunities, and stay organized throughout the job search process.

---

## 🚀 Live Demo

🔗 **Live Site:** (https://job-application-tracker-ten-alpha.vercel.app/)

---

## 📌 Features

- 📊 Dashboard with application statistics
- 💼 View all job applications
- 🔍 Filter applications by status
- 🟢 Applied Jobs
- 🟡 Interview Scheduled
- 🔴 Rejected Applications
- 📈 Real-time status summary
- 🎨 Clean and modern UI
- 📱 Fully Responsive Design
- ⚡ Fast and lightweight interface
